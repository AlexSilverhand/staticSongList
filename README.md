# Static Song List in C++

A simple C++ implementation of a static list class that stores up to 50 `Song` objects. It provides common list operations such as insertion, deletion, traversal, and string conversion. Designed for use in basic music library applications or data structure learning.

## Key Features  
- Stores up to 50 `Song` objects.  
- Supports insert, delete, retrieve, and list navigation.  
- Validates positions before performing operations.  
- Overloaded assignment operator and copy constructor.  
- String conversion and print support.

## Requirements  
- C++11 or higher  
- `song.hpp` and `listexception.h` with appropriate definitions
